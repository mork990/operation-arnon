# מבצע ארנון · הגדר

שתי משימות בגוף ראשון, בעברית, שרצות בדפדפן בלי התקנה (three.js).

- **משימה 1 · מבצע ארנון:** חילוץ החטופים בנוסייראת, 8 ביוני 2024.
- **משימה 2 · הגדר:** מפקד האירוע בהפגנה האלימה ליד קיר הגבול, 21 באוגוסט 2021.

**לשחק:** https://mork990.github.io/operation-arnon/

המשחק מפשט את האירועים. שמות החטופים והלוחמים והדיאלוגים בדויים.
